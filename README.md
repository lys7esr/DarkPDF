# DarkPDF

Convert any PDF into a beautiful, eye-friendly dark-mode PDF — entirely in your browser. No login, no upload, no tracking.

A heavily vibe-coded project born from one universal student experience: opening a PDF at night and getting absolutely flashbanged.

Built for readers, students, and late-night learners.

![Status](https://img.shields.io/badge/status-vibe--coded-purple)

## 🌐 Live Demo

https://darkpdf-reader.netlify.app/

## ✨ Features

- 🎨 Smart dark-mode conversion while preserving images and colourful graphics as much as possible.
- 🎭 Choose your reading shade:
  - AMOLED Black
  - Dark Gray
  - Midnight Blue
  - Sepia Dark
  - Low Contrast
- 🎚 Brightness & contrast controls for comfortable reading.
- 👁 Live side-by-side preview before downloading.
- ⚡ Web Worker pipeline for smoother performance.
- 🔒 100% client-side — your files never leave your device.
- 📱 Responsive UI for desktop and mobile.
- ⌨ Keyboard shortcuts for quick navigation.

## 🧱 Tech Stack

| Layer | Technology |
|---|---|
| UI | React 18 + Vite |
| Styling | Tailwind CSS |
| PDF Rendering | PDF.js (`pdfjs-dist`) |
| PDF Reconstruction | `pdf-lib` |
| Processing | Canvas API + Web Workers |

## 🚀 Quick start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Production build
npm run build

# Preview production build
npm run preview
```
